# HiveWork · 蜂巢智工 Logo 素材

本套素材由已生成的 Logo 展示板拆分导出，未修改产品代码。

- png/：9 个透明 PNG 主素材，另有 1 个深蓝背景版。
- icons/：橙色、深蓝两种应用图标，各含 16、32、48、64、180、192、512、1024 px。
- source/：原始展示板及透明背景源图。
- wallpapers/：科技蓝 HiveWork 远程桌面壁纸及生成说明。
- index.html：可直接打开的预览及单文件下载入口，含小尺寸检查。
- manifest.json：尺寸与透明度验证记录。

白色标志和反白组合用于深色背景。透明 PNG 的空白区域包含真实 Alpha 通道。应用图标保留自身底色，圆角外部透明。

## 格式与尺寸说明

本次为 PNG 位图素材拆分，未生成 SVG 矢量文件。原始展示板为 1536 × 1024 px；主素材保留拆分后的原始像素尺寸。512/1024 px 图标为缩放导出，不增加原图细节。

参考品牌色：蜂蜜橙 #FF9D00，深蓝 #14243B。生成图有轻微色彩变化，色值为设计参考。
